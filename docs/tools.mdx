## list_calculators

No input. Returns, for each calculator: `name`, `title`, `url`, `description`, `engine_version`, `revised` and
`inputs` (the input keys). Call it first when you do not know which keys a calculator takes; the full bounds,
options and defaults are in each tool's input schema.

## Input schema

The schema of a calculator is generated from the engine's input list when the server starts:

- `length` inputs accept a number or a string and carry `minimum` / `maximum` in the unit named in the description;
- `select` inputs carry their `enum`;
- `toggle` inputs are booleans;
- other inputs are numbers with their bounds;
- `system` selects `"imperial"` or `"metric"`.

Extra keys are refused, so a misspelled key cannot fall back to a default unnoticed.
